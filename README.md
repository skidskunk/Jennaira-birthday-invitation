# 🎀 Undangan Ulang Tahun Jennaira Nala Bestari

Website undangan ulang tahun ke-1 bertema **Hello Kitty**, mobile-first, dengan musik kotak musik Happy Birthday otomatis, confetti pita, countdown live, Google Maps, RSVP, serta dinding ucapan terintegrasi dengan **Supabase**.

## 🚀 Cara Menjalankan

### Jalankan Dev Server:
```bash
npm run dev
```

### Build untuk Produksi:
```bash
npm run build
```

---

## 🗄️ Database Supabase

Kredensial database tersimpan di file `.env`:
- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY`

Query tabel dan hak akses tersedia lengkap di file [`supabase-setup.sql`](./supabase-setup.sql).
